Project overview

Understanding fire activity across Greece

This project brings together satellite-detected burned-area perimeters and municipal fire-service totals to show how fire activity varies across space and time in Greece. It is designed to help users compare long-term patterns from Copernicus EFFIS with local municipality reporting from the Greek fire service.

Monitoring

Annual fire trends

Track where burned-area activity increases or declines across Greece using the year-by-year EFFIS record.

Comparison

Two-address analysis

Compare municipalities for different locations and investigate how local fire totals vary between places.

Context

Administrative boundaries

Use the Greece municipality layer to connect mapped fire data with official local geography and reporting.

What the map shows

The map displays Copernicus EFFIS satellite-mapped burned-area perimeters for Greece from 2006 to 2026. The timeline lets you select a year or view the combined 2006–2026 record. This allows the user to see where fire activity was concentrated and how the distribution changes over time.

How the comparison works

The comparison tool geocodes two addresses in Greece, identifies the municipalities containing them, and compares the reported burned-area totals for 2014–2018. These are municipality totals and should be read as local reporting summaries, not as exact measurements at a single address.

Data sources

  • Copernicus EFFIS burned-area perimeters and annual fire estimates, 2006–2026
  • Greek fire-service municipality totals for 2014–2018
  • GeoBoundaries administrative polygons for Greece
  • OpenStreetMap Nominatim for address search and geocoding

Methodological notes

MODIS and Sentinel-2 derived perimeters may miss smaller fires, and mapped boundaries may combine multiple fire events. The annual totals and perimeter maps are separate measures. The 2026 data is year-to-date and should be interpreted as partial. This project is intended as a visual exploration and comparative dashboard.

Project purpose

The goal of the site is to make complex forest-fire data easier to interpret. By combining spatial mapping, temporal analysis, and local comparison tools, it supports a clearer understanding of wildfire patterns in Greece and how they connect to administrative regions.
